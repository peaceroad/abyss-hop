# 深海潜行 - Abyss Hop 実装メモ

## 概要

**深海潜行 - Abyss Hop** は、ブラウザでそのまま開ける単一HTMLファイルのCanvasゲームです。  
プレイヤーは `🐟` を操作し、海流面を足場にしながら深海へ潜り続けます。画面は自動で下方向へスクロールし、魚が画面上部に流されすぎる、または画面下へ落ちすぎるとゲームオーバーになります。

- ファイル名: `abyss-hop.html`
- 実装形式: 単一HTMLファイル
- 外部ライブラリ: なし
- 外部画像: なし
- 描画方式: HTML Canvas 2D
- UI言語: 日本語
- 論理解像度: 800 × 600
- 表示比率: 4:3固定
- 保存機能: `localStorage` にベスト深度を保存

## ゲームの目的

海流面に乗りながら、できるだけ長く深海へ潜り続けることが目的です。  
深度は画面右上に `scroll` 単位で表示されます。

ベスト深度はブラウザの `localStorage` に保存され、次回起動時にも表示されます。

## 操作方法

| キー | 操作 |
|---|---|
| `B` | 左へ移動 |
| `F` | 右へ移動 |
| `P` | ホップ |
| `N` | ダイブ |
| `Enter` | タイトル画面から開始 / ゲームオーバー後に再スタート |
| `R` | ゲームオーバー後に再スタート |
| `Esc` | プレイ中は一時停止 / 一時停止中はタイトルへ戻る / ゲームオーバー中はタイトルへ戻る |
| `Space` | 一時停止中に再開 |

クリック操作は開始や再開には使いません。  
クリックはゲーム画面へフォーカスを当てるためだけに使います。

## 基本ルール

1. ゲーム開始時、魚は左端に接した長い初期海流面の上に配置されます。
2. 画面は自動で下方向へスクロールします。
3. 魚は海流面に着地できます。
4. `P` でホップし、`N` で下方向へダイブします。
5. 敵や障害物に当たるとゲームオーバーです。
6. 魚が画面上部に隠れても少しだけ猶予があります。
7. 上部猶予中は、魚本体ではなく上端の泡と警告表示で危険状態を知らせます。
8. 魚が上に流されすぎる、または下に落ちすぎるとゲームオーバーです。

## 登場キャラクター・障害物

| 表示 | 種類 | 役割 |
|---|---|---|
| `🐟` | プレイヤー | 操作キャラクター |
| `🐚` | 貝 | 海流面付近に出る障害物 |
| `🦀` | カニ | 海流面上を左右にパトロールする敵 |
| `🦈` | サメ | 水中を自由移動する敵 |
| `🐋` | クジラ | 中盤以降に出る大型敵 |

通常敵である `🐚`、`🦀`、`🦈` は、プレイヤーの `🐟` と同じく30px基準で描画します。  
`🐋` は大型敵として、通常敵よりかなり大きく描画します。

## 難度と敵出現

敵は序盤から比較的早く登場します。  
ただし、開幕直後の足場と直近の着地点は安全にし、初見でも即死しないようにしています。

主な出現開始タイミング:

| 対象 | 出現開始目安 |
|---|---:|
| 貝 | 2.0秒後 |
| カニ | 2.4秒後 |
| サメ | 2.8秒後 |
| クジラ | 24秒後 |

ゲーム開始時点でも、少し先の海流面に貝・カニ・サメを初期配置し、敵が出るまでの待ち時間を短くしています。

## 画面・スケーリング

ゲーム内部は 800 × 600 の論理解像度で処理します。  
実際のCanvas表示はブラウザのビューポートに合わせ、4:3比率を維持したまま最大フィットします。

CSS側では以下の方針です。

```css
width: min(100vw, calc(100dvh * 4 / 3));
height: min(100dvh, calc(100vw * 3 / 4));
aspect-ratio: 4 / 3;
```

Canvas側では、実表示サイズと論理解像度の差を `ctx.setTransform()` で吸収しています。  
これにより、魚・敵・足場・HUD・当たり判定は同じ論理座標系で扱われ、画面サイズが変わっても相対的な位置関係が崩れにくくなっています。

## 幅スケール調整

物理パラメータの一部は、画面幅基準で調整しやすいように `widthScale()` / `scaled()` を通す形にしています。

対象:

- ホップ力
- ダイブ力
- 重力
- 左右移動加速
- 最大横速度
- ゲームオーバー時の落下重力

現在の基準幅は800pxです。

```js
function widthScale() {
  return CFG.logicWidth / 800;
}

function scaled(v) {
  return v * widthScale();
}
```

現状では `CFG.logicWidth` が800なので、スケール値は1です。  
将来的に論理解像度や基準幅を変えた場合も、物理値をまとめて調整しやすい構造です。

## ホップ・ダイブ

ホップ力は初期値から約1.25倍に調整されています。

- 元のホップ速度: `-520`
- 現在のホップ速度: `-650`

敵の見た目サイズと当たり判定を強めたため、回避性能を少し上げています。  
ただし、前回の1.5倍ほど強くはせず、操作感が軽くなりすぎないようにしています。

## 当たり判定

プレイヤーと敵の当たり判定は、絵文字の見た目に近い円形判定を採用しています。  
完全なピクセル単位の判定ではありませんが、「触れて見えるのに当たらない」違和感を減らす方向で調整しています。

現在の方針:

- `🐟` の見た目は30px
- 通常敵も30px
- 魚側の当たり判定縮小量を小さめに設定
- 貝・カニ・サメの半径を14pxに統一
- クジラは大型敵として別半径を使用

当たり判定の基本式:

```js
const rr = playerHitRadius() + enemy.r;
if (dx * dx + dy * dy < rr * rr) {
  gameOver();
}
```

## ゲームオーバー演出

ゲームオーバー時は、画面全体が暗くなります。  
加えて、現在は `🐟` がやられた感じを出すため、専用の死亡演出を入れています。

演出内容:

1. 当たった位置に死亡用の魚 `deathFish` を生成
2. 少し上へ跳ねる
3. 回転しながら下へ落下
4. 小さな気泡を出す
5. 画面は暗くなり、ゲームオーバーUIを表示

通常プレイ中の魚描画と、ゲームオーバー時の魚描画は分離しています。

## 泡の扱い

常時背景泡を表示すると、魚・敵・海流面の視認性を少し妨げるため、通常プレイ中は基本的に抑制しています。

泡を表示する主な場面:

- タイトル画面
- ゲームオーバー時
- 魚が画面上部に隠れた危険状態

上部に隠れた時は、泡を警告UIとして使います。

## 上部アウト猶予

魚が画面上部へ少し隠れても、即ゲームオーバーにはなりません。  
ただし、一定以上隠れるとゲームオーバーになります。

危険状態では以下を表示します。

- 上端の暗いグラデーション
- 泡
- `上へ流されている` の警告テキスト

この状態は `topDanger` で管理しています。

## 状態管理

ゲーム全体の状態は `state` で管理しています。

| state | 内容 |
|---|---|
| `title` | タイトル画面 |
| `intro` | 開始直後の短い演出 |
| `playing` | プレイ中 |
| `paused` | 一時停止中 |
| `gameover` | ゲームオーバー |

## 主な実装構成

### 初期化

- CanvasとDOM要素を取得
- `localStorage` からベスト深度を読み込み
- 泡オブジェクトを初期化
- Canvasを4:3表示にリサイズ
- キーボード入力とフォーカスイベントを登録
- `requestAnimationFrame` でメインループ開始

### メインループ

メインループは `frame(now)` で実行されます。

主な処理:

1. 経過時間 `dt` を算出
2. 固定ステップで物理更新
3. 状態別に処理を分岐
4. 背景・足場・敵・プレイヤー・HUDを描画
5. 次フレームを予約

### 物理更新

`updatePhysics(dt)` でプレイヤーの物理処理を行います。

- 重力
- 左右移動
- 摩擦
- 空中抵抗
- 壁制限
- 海流面への着地判定
- 敵との衝突判定

### 敵・泡・パーティクル更新

`updateEntities(dt)` で以下を更新します。

- サメの自由移動
- クジラのゆっくりした自由移動
- カニの足場上パトロール
- 泡の移動
- 上部危険泡の移動
- パーティクルの寿命管理

### スクロール更新

`updateCameraAndScroll(dt)` で画面スクロールとゲームオーバー判定を行います。

- スクロール速度の増加
- カメラY座標の更新
- 最大深度の更新
- 上部アウト判定
- 下部アウト判定

### 地形生成

`generateUntil(targetY)` で、先の海流面と敵を生成します。

特徴:

- 最低1つの安全候補足場を生成
- ときどき画面端に接する海流面を配置
- 深度帯によって足場配置の雰囲気を変える
- 敵は安全足場を完全に塞がないように配置
- 難度は時間・深度・波を組み合わせて変化

